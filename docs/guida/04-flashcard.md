# 4 Le flashcard (cartella content/flashcards)

```
{ "schema": 1, "cards": [
  { "id": "fis-u1-c001", "topic": "fis-u1-t1",
    "front": "Velocità media",
    "back": "Spazio percorso diviso il tempo impiegato: v = Δs / Δt (m/s).",
    "source": "Dispense di cinematica" }

```

- `front`: la domanda o il termine; `back`: la risposta, breve e completa.
- Facoltativo `ref` verso il libro, come per le domande (capitolo 3.4).
- Una carta, un'informazione: definizioni, formule con il significato dei simboli, eccezioni, confronti.
- Prima di girare la carta, l'app invita a spiegare la risposta a parole: retro chiari e autosufficienti aiutano a confrontarsi.
